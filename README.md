# SONSÜZ ÇAY BEKLEYİŞİ SİMÜLATÖRÜ

**Dikkat: Bu proje ciddi bilimsel bir çalışmadır.**

Çay demlenirken geçen zaman, aslında kuantum köpüğünde meydana gelen mikro-çay partiküllerinin evrenin termodinamik dengesini bozmasıyla ilgilidir. Bu simülatör, o kutsal bekleme anını ölülsüzleştirir.

## Özellikler
- Gerçek zamanlı çay demlenme sayacı (yani sleep fonksiyonu)
- Abartılı bilimsel açıklamalar
- Rastgele "çay bitti mi?" panik atakları
- Hiçbir şey yapmayan ama çok önemli görünen kod

## Kullanım
```bash
python cay_bekle.py
```

Sonra otur ve bekle. Gerçekten bekle. Hayatın geçiyor.
